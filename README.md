# Chalchitra · Free mobile video editor

A free video editor that runs in your phone's browser. You can install it as an app, and all editing happens on the phone; nothing is uploaded.

**Features:** cut, trim, split, freeze frame, slow-mo and speed, crop, rotate and flip, clip animations, transitions, filters and effects, animated text and stickers, music and phone recordings, voiceover, voice effects, voice/music mix modes, sound-reactive animations, auto-saved projects, and export (save to gallery or share).

Best in Chrome on Android. Open the GitHub Pages link and choose **Add to Home screen**.
